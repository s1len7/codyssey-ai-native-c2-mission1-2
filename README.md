# codyssey-ai-native-c2-mission1-2

`영화_수정전.html`에서 오류를 직접 재현하고, AI에게 본 장면을 전해 원인을 물으며 오류를 수정하는 미션 1-2의 결과물입니다.

## 파일 구성

| 파일 | 설명 |
|---|---|
| `영화_수정전.html` | 오류가 있는 원본 영화 티어리스트 (수정 전 보관용) |
| `영화_수정1.html` | 오류를 고친 파일 (있다면) |
| `미션2_기록.md` | 발견한 오류, AI 대화, 수정 기록 |
| `backup/` | 미션 안내 문서와 샘플 (`[미션2]샘플과 코랩세션질문지`) |

## 샘플 실행

`backup/[미션2]샘플과 코랩세션질문지/샘플/영화_수정전.html`을 더블클릭하면 브라우저에서 열립니다. 외부 파일·로그인·서버 실행 없이 HTML 한 장으로 동작합니다.

## 기획서 요약 (샘플)

- **누가 쓰나**: 나와 영화를 좋아하는 친구들
- **무엇을 하려고**: 본 영화를 S·A·B·C 등급으로 나누어 내 취향을 정리
- **화면과 동작**: 위에 S·A·B·C 칸, 아래에 아직 안 정한 영화 카드. 카드를 누르고 등급 글자를 누르거나 끌어 놓으면 해당 칸으로 이동. 제목 입력 후 ‘추가’로 새 카드 생성. 브라우저에 자동 저장. ‘처음으로’로 초기 목록 복원
- **필요한 자료**: 기생충, 인터스텔라, 라라랜드, 센과 치히로의 행방불명, 어벤져스: 엔드게임, 범죄도시, 타이타닉, 토이 스토리 (총 8편)
- **완성 기준**: 8개 영화와 새로 추가한 영화 모두 S·A·B·C·미분류로 이동 가능. 한 칸에만 있고 옮긴 칸에 남음. 제목 입력 시 새 카드 생성. 같은 브라우저에서 다시 열어도 유지. 좁은 화면에서도 오른쪽 잘림 없음. ‘처음으로’ 시 8개 모두 미분류로 복원. 빈/공백 제목은 카드 미생성

## 미션 1-2 기록

`영화_수정전.html`을 덮어쓰지 않고 보관한 뒤, ‘처음으로’를 누르고 완성 기준을 하나씩 시험해 오류를 좁혔습니다. 발견한 오류와 수정 내용은 `미션2_기록.md`를 참고하세요.
